# Code of Conduct

## Our standard

We are committed to making participation in this project respectful,
constructive, and welcoming. Harassment, discrimination, personal attacks,
intimidation, and deliberately disruptive behavior are not acceptable.

Participants should communicate with empathy, assume good faith, provide
actionable feedback, and focus criticism on ideas and code rather than people.

## Enforcement

Project maintainers may remove comments, close discussions, or restrict
participation when behavior violates this code. Report concerns privately to
the repository owner. Reports will be handled confidentially and reviewed
fairly.
